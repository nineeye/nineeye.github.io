## 작업 필수 4대 규칙
1. 자료가 필요하면 정확한 바로 다운로드 주소를 제공한다.
2. 무료 오픈소스를 먼저 검토하고 부족한 부분만 개발한다.
3. 쉬운 개선은 한 번에 큰 묶음으로 수행한다.
4. 좋은 아이디어를 적극 검토해 QA 후 반영한다.

## V12 결과
- 여섯 산업별 기능 데모 화면의 **브랜드별 완전한 새 시각 체계**: 산업재 설계도, 발레 에디토리얼, 건축 평면도, 자연 숙박, 단체 관리자 워크스페이스, 의료 안내
- 여섯 사이트의 기존 **실제로 동작하는 JavaScript 코드는 그대로 유지**. 견적, 일정, 공사비, 숙박요금, 게시판, 진료 일정 등
- 새로운 브랜드 아트 6종: 오리지널 HTML/CSS로 그려진 독립 시각 요소 (외부 사진/아이콘 없음)
- 여섯 페이지별 설계 의도, 다른 업종 탐색, 가상 샘플·운영 기능 미연결 안내
- 실제 최신 리뉴얼 페이지를 Chromium으로 렌더링해 추출한 독립 미리보기 6개 SVG(내부 WebP 스크린샷)
- **showroom-v12.html**: 분야별 구분, 검색, 사용 가능한 사이트로 바로 연결, 모바일·키보드 지원
- 기존 42개 샘플·V7 시안 제작기·V8 기능 설계·V9 접수 기반·V10 운영 진단은 삭제하지 않음

## 비용·상업 라이선스
- Bootstrap MIT: https://github.com/twbs/bootstrap — 검토만 했으며 V12에 추가하지 않음
- Heroicons MIT: https://github.com/tailwindlabs/heroicons — 검토만 했으며 V12에 추가하지 않음
- 업종 아트는 사용자 소유 개발 코드의 오리지널 HTML/CSS. 기존 스크린샷 역시 우리 HTML 페이지의 브라우저 캡처.
- 추가 유료 API 없음, CDN 없음, 외부 이미지·폰트·테마 복제 없음.

## 명확한 운영 구분
- 여섯 페이지는 실제 고객 납품 실적이 아닌 **가상 브랜드 기능 시연**이다.
- 가상 견적, 수업 희망일, 숙박 날짜, 임시 게시판, 진료 시간표 등은 실제 운영 데이터가 아니다.
- 서버 DB·예약 확정·카드결제·회원 로그인은 별도의 개발·보안·실사용 검수 과정이 필요하다.
