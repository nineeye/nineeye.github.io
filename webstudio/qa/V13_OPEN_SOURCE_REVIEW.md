# V13 commercially licensed source selection
Commercially usable source candidates were reviewed, but not copied:
- Start Bootstrap free themes (MIT): https://startbootstrap.com/licenses
- Heroicons (MIT): https://github.com/tailwindlabs/heroicons
- Cloudflare Pages headers and static asset controls: https://developers.cloudflare.com/pages/configuration/headers/

For this 36-page branding refactor, the original project already had valid HTML/CSS/JS and functional demos. Replacing it with Bootstrap or a React framework would add installation, regression risk, load time and maintenance burden. We instead authored custom original vector artwork, CSS and a small standalone gallery script. No external photos, downloaded templates, copied logos, paid APIs, tracking scripts, fonts or cloud build tools are bundled. No copyright or license obligations from external source are introduced by V13 additions.
