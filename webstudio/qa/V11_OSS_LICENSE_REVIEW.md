# V11 공개 소스 조사 결과

- [AstroWind](https://github.com/arthelokyo/astrowind): MIT. 풍부한 정적 사이트 위젯과 SEO 구조가 유리하지만 Astro/Tailwind 도입·빌드·운영 난이도 증가. 이번 파일럿에는 미포함.
- [Start Bootstrap](https://startbootstrap.com/licenses): 무료 템플릿 MIT. 업종별 기본 구성을 빠르게 만드는 데 적합하나 웹스튜디오 메인 시그니처 디자인은 별도 아트 디렉션 권장. 이번 파일럿에는 미포함.
- [Flowbite](https://flowbite.com/docs/getting-started/license/): 공개 UI 컴포넌트 MIT. 향후 관리자/폼 개선에 적합하며 Pro 별도 라이선스 주의. 이번 파일럿에는 미포함.
- [Pretendard](https://github.com/orioncactus/pretendard): OFL 1.1. 시스템 설치 여부에 따른 CSS 폰트 스택만 사용, 폰트 파일 미포함.
- 스크린샷 6개: 올파일원 자체 가상 데모의 HTML과 CSS에서 직접 렌더링. 다른 제작사의 저작물을 무단 복제하지 않음.
- 상업 사용 전 실제 납품 시 외부 이미지·폰트·템플릿을 추가한다면 별도 라이선스 검증 필요.
