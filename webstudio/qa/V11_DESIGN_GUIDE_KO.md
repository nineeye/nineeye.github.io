# ALLFILEONE WEB STUDIO V11 | 디자인 고급화 파일럿

2026-11-07

## 반드시 지킬 네 가지
1. 필요한 자료는 바로 다운로드 가능한 정확한 주소를 안내한다.
2. 무료 공개 소스를 우선 조사하고 부족한 부분만 개발한다.
3. 여러 개선을 한 번에 묶어서 작업한다.
4. 유용한 아이디어가 생기면 적극 검토하고 반영한다.

## 디자인 문제 진단
현재 메인 사이트(V10)는 짙은 청록색·유사한 직사각 카드·가상 브라우저 일러스트 중심이어서, 42개 실제 HTML 시연 사이트의 강점을 충분히 보여주지 못한다. 업종별 샘플의 형태가 비슷하게 느껴지므로 프로젝트의 질을 강조하기보다 수량을 강조하는 효과가 난다.

## V11 실험 방향 — Proof-led Editorial
- 화이트/아이보리 기반 여백, 짙은 잉크톤, 절제된 유기적 녹색, 러스트 포인트 컬러.
- 한눈에 읽히는 브랜드 메시지와 큰 헤드라인; 작은 글자/넓은 사이드 레이블.
- 비대칭 편집형 화면, 대형 대표작 1개 + 보조 대표작 2개.
- 각 대표작의 '사업 문제 → 해결 시나리오 → 실제 눌러보는 데모' 순서.
- 가짜 브라우저 일러스트 대신 기존 6개 실제 HTML 데모의 브라우저 렌더링을 캡처한 스크린샷 사용.
- 브랜드/업무/납품을 3개의 명확한 서비스로 정리하고 CTA를 과잉 노출하지 않음.
- 실제 고객 납품 실적이나 가상의 후기/수상 사실을 표시하지 않음.
- 3개 대표 스크린 전환, 모바일 메뉴, 4단계 프로세스, 키보드 탐색, 저모션 대응.

## 실제 검증
- Chromium 내부 주입 렌더링 + 클릭 시험 1440, 1024, 768, 390, 320px: 58/58 PASS (최종 코드)
- 이미지 출처: 직접 만든 6개 specialty HTML의 실제 기능 구간을 Chromium으로 렌더링 후 WebP 및 SVG 포장으로 캡처; 외부 사진·로고 사용 없음
- 로컬 파일 및 localhost 브라우저 이동이 정책상 제한되어 실제 사이트 URL을 통한 브라우저 E2E 검사는 미실시
- Cloudflare V11 게시 상태: GitHub 병합 전 미확인

## 제품 현황
현재 V11은 `/design-v11.html` 시범 페이지이고 기존 `index.html`은 수정하지 않음. 기존 42개 데모와 V7~V10 기능은 유지됨. 사용자 반응·최종 검증 후 해당 디자인 시스템을 메인과 업종별 샘플로 확대 적용 가능.
