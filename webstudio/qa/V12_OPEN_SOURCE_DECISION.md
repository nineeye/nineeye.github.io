# V12 무료 소스 우선 검토 기록

상업적 재판매 가능 조건을 기준으로 Bootstrap(MIT), Heroicons(MIT)를 공식 저장소에서 검토했다.
- https://github.com/twbs/bootstrap
- https://github.com/tailwindlabs/heroicons

기존 HTML·CSS·JavaScript 구성에는 추가 프레임워크가 없어도 필요한 UI를 구현할 수 있다. 두 소스를 새 의존성으로 추가하면 번들 크기와 관리 대상이 늘어난다. **이번 변경에서는 직접 만든 CSS 디자인 토큰, 오리지널 장식, 기존 검증된 JS 기능을 재사용했다.** 제3자 코드·사진·폰트·아이콘 다운로드, 라이선스 복사 의무가 새로 발생하는 에셋은 없다.

무료로 내려받을 수 있어도 상업적 복제·재배포 권한은 별도로 검토해야 하며, 소스의 자산별 라이선스와 저작권 표기를 확인해야 한다.
