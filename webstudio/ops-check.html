ACTIVATION GUIDE

실제 접수 활성화를 위한 설정

연결되지 않은 항목을 먼저 준비하고 검증해야 합니다. 안전한 기본값은 자동 접수 비활성화입니다. 계정 설정을 자동으로 변경하거나 비용을 발생시키지 않습니다.

01

D1 데이터베이스 만들기

Cloudflare에서 D1을 만들고 migrations/0001_inquiries.sql 스키마를 적용합니다.

공식 무료 설정 안내 ↗
02

Pages에 DB 연결

allfileone-webstudio → Settings → Bindings에서 D1 변수명을 INQUIRIES_DB로 설정합니다. 변경 후 다시 배포합니다.

공식 바인딩 방법 ↗
03

보안 비밀 키 설정

Cloudflare 비밀 변수에 STUDIO_ADMIN_TOKEN과 TURNSTILE_SECRET_KEY를 등록하고, 공개 사이트 키 TURNSTILE_SITE_KEY를 설정합니다. 비밀 값은 GitHub에 올리지 않습니다.

Turnstile 등록 방법 ↗
04

개인정보 안내 및 최종 승인

실제 사업자 정보와 보관·삭제 절차를 확인한 후에만 PRIVACY_POLICY_APPROVED=1, PUBLIC_INBOX_ENABLED=1을 설정합니다. 모두 갖춰지면 실제 서버 연결을 재검증합니다.

고객에게 보일 안내 확인 ↗
비용 0원 우선 안전장치: Cloudflare 무료 한도와 서비스 약관을 확인하고, 유료 플랜 전환·자동 결제·사용량 초과 과금은 승인 없이 설정하지 않습니다. Cloudflare Pages → Settings → Runtime의 Fail closed 설정도 점검하세요. Functions 한도 도달 시 인증을 우회하는 정적 응답이 나오지 않도록 하기 위함입니다. 실제 이메일 발송은 별도 연결되지 않았으므로 접수 완료와 메일 발송을 혼동하지 않습니다.

설정 전에 실수부터 줄입니다.

실제 가동이 확인되기 전에는 nineeyes@naver.com 이메일 문의가 기본 채널입니다.
