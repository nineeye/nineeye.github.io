# 올파일원 웹스튜디오 V81 — 실운영 제작 범위 협의기

## 이번 변경
- `webstudio/feature-scope-v81.html`: 12개 업종 × 8개 기능을 선택해 실제 제작 범위 초안을 만드는 무료 브라우저 화면
- 기능은 **가상 시연 가능 / 현재 미구현**으로 구별하되, 96개 항목 모두 실운영 적용 시 별도 설계·검증이 필요함을 명시
- 콘텐츠·가격 정책·업무절차·자료파일·외부 연동·예약·보안·회원 등 검토 위험 구분
- 시기·예산 참고 범위·운영 준비 5항목·추가 요청의 통합 TXT 내보내기/복사/인쇄, 수동 이메일 초안
- 홈페이지·기능목록·디자인비교·상품안내·기존 36개 데모의 진입 링크 추가
- 직접 다운로드 TXT는 브라우저에서 생성. 개인정보·문의 자동 전송 또는 저장 없음

## 운영 한계
- V80 기존 가상 시연 84개는 운영/예약/회원/결제에 연결되지 않음. V81은 실제 운영을 약속하거나 구현한 것이 아님.
- 가격 29/59/99만원부터는 기존 예시 시작가이며 선택한 기능은 자동 포함되지 않음.
- `mailto:`는 고객 이메일 앱을 여는 것뿐. **실제 수신 미검증**. 완전본 TXT를 직접 첨부해야 함.
- Cloudflare 공개 사이트 배포는 이 환경에서 접근 불가. **실제 배포 미검증**.

## 사용
`webstudio/feature-scope-v81.html` 파일을 브라우저에서 열거나 Cloudflare 배포 후 동일 경로에서 기능을 선택합니다. 고객은 TXT를 저장하거나 복사해 상담사에 직접 전달합니다.
