# 올파일원 웹스튜디오 V43 — 해외 시장 조사 반영: 3개 업종 대표작 체험 강화

2026-11-08 (Asia/Seoul) | 사업 목표: **국내 고객이 실제로 홈페이지 제작을 의뢰하는 전문 제작사**.

## 개발 방향
세계적으로 AI/템플릿이 소개형 사이트 제작을 대중화하면서, 제품화된 업종별 실제 기능·브랜드 디자인·운영·문의 전환이 차별화 수단으로 중요해짐. 단순 사이트 수 확대보다 **대표 업종 3종의 실사용 체험**에 집중한다.

## 이번 구현
- 제조·도매 `for-manufacturing.html`: **가상 부품 8개**를 제품군·재질·키워드로 필터링하고 규격/최소주문 단위 *예시*를 비교한다.
- 학원 `for-academy.html`: **가상 강좌 8개**를 학년·요일·키워드로 검색하고 관심 강좌 메모를 만든다. 실제 등록·시간표/잔여석은 아니다.
- 인테리어 `for-interior.html`: **가상 공간 콘셉트 8개**를 공간 유형·시공 범위·검색어로 필터링하고 시공 상담 참고 메모를 만든다. 실제 시공 사례·후기는 아니다.
- 모든 대표 페이지는 **실제 필터·검색·선택/제외·초기화·클립보드 복사·TXT 저장** 가능. 외부 API/서버/쿠키/유료 서비스 없이 동작.
- 3개 판매 페이지의 기존 `V38` 기능 선택 폼과 `V39` 상담서 인계는 유지. 선택한 견본을 클릭하면 해당 허용 기능 범주(제조 견적·학원 시간표·인테리어 포트폴리오)를 자동 체크한다.
- 견본의 상세 내용은 URL/서버로 전송하지 않는다. **기능 범주만** 기존 상담 경로로 넘기며, 상세 내용은 고객이 TXT/복사본을 수동 제출.
- 3개 페이지 히어로에서 새 `#live-demo` 영역으로 직접 이동. 메인 홈 업종별 상품 카드의 설명을 새 체험 기능에 맞게 수정.
- V42의 36개 데모, 48개 업종 업무기능, 3개 판매 페이지, V41 상품·계약 안내, V42 웹메일 안내 코드는 이외에 변경 없음.
