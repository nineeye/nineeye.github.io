# 올파일원 웹스튜디오 V39 — 선택한 기능을 실제 상담 준비서까지 유지

2026-11-08. 본래 목표: 업종별 고객이 실제로 제작을 의뢰하는 신뢰 높은 판매용 웹사이트.

## 발견 및 수정한 고객 전환 문제

V38의 제조·도매, 학원·교육, 인테리어·시공 페이지에서 체크한 4가지 기능 중 선택 내용을 상담으로 가져가지 않아 고객이 다시 입력해야 했음.

- 3개 판매 페이지 × 각 4개 상담 버튼의 `source=demo`를 `source=sector`로 구분.
- 공유 `assets/v38-solutions.js`: 고객 체크 상태를 읽고 **허용한 기능 ID 최대 4개**만 모든 상담 링크의 `scope`에 넣음. 선택 해제 시 URL에서도 제거.
- `assets/v39-sector-handoff.js`: 상담 페이지에서 source, industry, scope를 **3개 업종별 화이트리스트**로 검증 후 기능명만 복원. 원본 URL 텍스트는 신뢰하지 않고 `textContent`로만 출력.
- 기존 상담폼의 `details`에 안전한 자체 설명을 넣고 V26에 정확한 기능명 요약도 연결해 메일 길이 제한 축약 시에도 `필요 기능` 줄을 통해 선택 기능을 보존. 미리보기·TXT 저장·복사·mailto 이메일 초안에 반영. 거짓 예약·결제·접수 없음.
- 해당 업종과 현재 선택한 기능을 설명하는 반응형 알림; 업종 변경 시 자동 입력한 과거 참고 내용을 취소 또는 재검토 경고.
- 원본 V36 진단, V37 36개 디자인, V38 판매 페이지 구성 및 라이선스는 유지.

## 자체 검증

- 실제 V38 판매 페이지 3개의 수정된 HTML/JS와 상담 가져오기 신규 JS를 **격리 Chromium**으로 실행하여 **945/945 검증 PASS**: 3 업종 × 4기능의 모든 선택 조합, 4개 상담 링크 일치, 세부 요청/관련 기능 복원, invalid URL 차단, 업종 변경, 다중 화면 폭 검사.
- GitHub 실제 V39 브랜치 파일 8종과 기존 V26 상담 코드 교차 검사 **23/23 PASS**.
- JS Node 문법검사 통과. 외부 API나 브라우저 저장소 사용 없음.
- `mailto:`는 방문자 이메일 프로그램의 새 메시지만 연다. **실제 이메일 전송과 수신 검증은 하지 않았음**.
- Cloudflare 공개 URL은 외부 조회에서 접근할 수 없었으며, **실사이트 배포 성공 판정은 보류**. 브라우저 시험은 네트워크 URL E2E가 아닌 격리 HTML/JS 테스트임.
