# 올파일원 웹스튜디오 V51 — 1분 문의 → 상세 상담 끊김 없는 연결

날짜: 2026-11-08. 목표: **첫 실제 유료 홈페이지 제작 의뢰**. 신규 수익·고객·메일 수신을 꾸며서 보고하지 않는다.

## 실제 구현

- V49의 업종별 빠른 문의와 V26/V47의 기존 상세 상담 화면을 일회성으로 연결한다.
- 빠른 문의에서 업종, 기능, 자료 규모, 희망 일정, 참고 예산, 메모를 선택하면 `작성 내용 유지하고 상세 상담하기` 버튼으로 안전하게 이동한다.
- 작성 메모는 URL이 아닌 탭 단위 `sessionStorage`에 최대 15분 동안 보존한다. 받는 화면에서 읽자마자 삭제한다. 서버 전송·쿠키·추적·메일 자동 발송 없음.
- 제조, 학원, 인테리어 3업종 각 기능 키와 상세 상담 항목을 허용된 대응표로 연결한다. 입력 값을 HTML로 실행하지 않는다.
- 상세 상담 항목 700자 길이를 넘길 경우 원본을 별도 패널로 표시하고 복사 가능하게 안내한다. 기존 V47 전체 문의 TXT·복사 기능과 함께 사용 가능하다.
- `CTRL/SHIFT/새 탭` 탐색·브라우저 저장 차단 시 잘못된 발송/접수 성공을 표시하지 않는다.

## QA 결과 (한계 명시)

- V49의 **실제 빠른 문의 HTML/CSS/JS**에 V51 코드를 합쳐 격리 Chromium 320/360/390/768/1280/1440px × 3업종, 정상·변조·만료·중복 방지 케이스 **344/344 PASS**.
- 상세 상담 부분은 승인된 필드 모양의 **격리 테스트 화면(fixture)**, `sessionStorage`는 모의 저장소를 사용했다. 실제 동일 출처 간 이동·Cloudflare 공개 렌더링 검증이 아니다.
- Python/Node 정적 검사 **64/64 PASS**. V50 소스 안전 패치·재실행·구버전 거부 **15/15 PASS**. 합계 **423/423**.
- 실제 이메일 수신, 검색 도구 소유확인/색인, 유료 계약 완료는 **HOLD**.

## 국내 검색 및 영업 준비

기존 업종 판매페이지 각각에 고유 FAQ·제품 설명·시연이 있고, V49 간편 문의 + V51 상세 상담 연결로 고객의 다음 행동을 단순하게 한다. 고객에게 실제 납품 경험이나 실거래를 암시하지 않는다.

- 네이버 서치어드바이저 공식: https://searchadvisor.naver.com/guide/faq-start-register — 사이트 등록 없이도 자동 수집 가능하나 소유확인을 통해 수집·색인 상태를 확인한다.
- 네이버 URL 검사: https://searchadvisor.naver.com/guide/url-inspection — 페이지 상태·색인 여부.
- Google 검색 공식: https://developers.google.com/search/docs/fundamentals/seo-starter-guide — 실제 사용자에게 도움이 되는 고유한 콘텐츠 우선.
- Google 사이트맵: https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap — 사이트맵 제출은 색인 보장 아님.

소유자 로그인 없이 네이버·Google에 임의 제출하거나, 메일 발송 버튼을 자동으로 누르지 않는다.
