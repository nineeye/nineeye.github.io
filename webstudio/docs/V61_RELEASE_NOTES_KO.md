# AllFileOne WebStudio V61 — 실제 고객 문의의 빠진 업종 보완 + 전체 정적 사이트 품질 감사

## 이번 수정

1. 기존 `webstudio/inquiry.html`의 실제 접수 후보 업종에 음식점·카페, 뷰티·미용, 물류·운송을 추가했습니다.
2. 클라우드 접수 기능이 비활성화됐을 때도 6개 업종의 1분 이메일 문의서, 상세 상담서, 범위 협의표로 바로 이동할 수 있게 했습니다.
3. 기존 가상 기능형 시연을 실제 고객 납품 사례로 오인할 수 있는 문구를 수정했습니다.
4. 선택적 Cloudflare D1 문의 화면은 사용자 정보가 아닌 **공개 업종 ID**만 URL로 받아 사전 선택하도록 개선했습니다. 보안 키, DB, 유료 API 설정은 건드리지 않았습니다.
5. 신설 `tools/v61_site_integrity.py`는 순수 Python 표준 라이브러리로 HTML/CSS/사이트맵/앵커/메타 버전을 검사합니다. 출력은 한국어 TXT와 JSON입니다.
6. `RUN_V61_SITE_AUDIT.cmd`는 무료 공개 GitHub 소스를 임시 폴더에 내려받아 로컬 정적 검사를 실행하고 Windows `Downloads`에 기록을 남깁니다. Git·Python이 없거나 인터넷이 차단되면 HOLD와 원인을 기록하며, PowerShell 실행 정책을 변경하지 않습니다.

## 실제 검증 범위와 한계

- GitHub `main`의 **77개 HTML**에 대해 정적 href/src 파일 존재를 대조한 결과 누락이 없었습니다. 검사 당시 913개 파일 참조를 조회했습니다(인라인 JavaScript에서 만드는 동적 URL 제외).
- 자동 정적 검사기 자체 **31개 unittest**가 PASS였습니다. 테스트에는 누락 파일, 오래된 버전, 중복 ID, 앵커 오류, CSS 리소스 누락, 잘못된 사이트맵, CLI HOLD 등이 포함됩니다.
- Cloudflare Pages GitHub 검사 성공과 공개 서버 HTTP 접속/브라우저 화면·이메일 실수신은 별개입니다. 이 도구는 후자를 확인하지 못합니다.
- 이번 통합 ZIP은 변경 소스와 QA·이전 릴리스 증분 파일을 포함합니다. **전체 웹사이트 원본 저장소는 GitHub `nineeye/nineeye.github.io`의 `main/webstudio`**입니다.
- `webstudio/inquiry.html`의 서버 접수는 Cloudflare D1/Turnstile/운영자 승인 환경이 완성돼야 활성화됩니다. 현재 실제로 켜져 있다고 주장하지 않습니다.
