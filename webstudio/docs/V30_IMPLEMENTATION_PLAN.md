# 올파일원 웹스튜디오 V30 — 기능 증명형 갤러리

작성 기준: 2026-11-07 / 상용화 목표: 방문자가 업종별 시연 페이지의 실제 기능을 쉽게 찾아 체험하고 제작 상담으로 이어지게 한다.

## 발견한 문제
- V29 메인 갤러리는 실제 데모 화면을 표시하지만, **어떤 기능이 작동하는지 카드를 펼치기 전 알 수 없다**.
- 12업종 48개 프런트엔드 기능이 존재하지만, 각 기능에 직접 도달하려면 데모를 열고 한참 스크롤하거나 찾아야 한다.
- 기존 V28 데이터와 별도의 수동 마케팅 문구를 만들면 명칭이 어긋날 위험이 있다.

## 이번 변경 범위
- [x] `assets/v28-catalog.js`를 메인 홈페이지에서 `assets/main.js`보다 먼저 읽는다.
- [x] 메인 카드 12개의 하단에 해당 업종의 **실제 기능 이름 4개**를 표시한다. 목록은 기존 V28 카탈로그에서 직접 읽는다.
- [x] 각 기능 링크는 해당 업종/스타일을 유지한 채 `?feature=0~3#v28-tools`로 이동한다.
- [x] 시연 페이지에 기능 탭을 생성한 뒤 요청받은 특정 탭을 선택하고 화면을 이동시킨다.
- [x] 0~3 이외의 입력은 기본 탭으로 안전하게 처리하며, URL에서 코드를 실행하지 않는다.
- [x] 새 CSS에서 2열 기능 목록, 44px 내외 터치 영역, 명확한 키보드 초점, 모션 감소 환경 대응.
- [x] V30 자동 버전 표시, 현행 버전 포인터, 릴리스 매니페스트, 공개 점검기 갱신.
- [ ] GitHub 메인 브랜치에 기존 V29 디자인/상담/필터 기능 보존하며 최소 변경 (병합 전 검증 중).

## 상용화/진위 관련 규칙
- 기능은 **가상 데이터 기반 브라우저 시연**이고, 실제 주문·예약·상담 접수/결제의 성공을 뜻하지 않는다.
- 고객 납품 실적은 검증되지 않았으므로 표시하지 않는다.
- 추가 유료 API, 분석 추적 스크립트, 외부 서비스 의존성을 새로 도입하지 않는다.
