# V52 · 3대 업종별 사이트 독립 시연 전시장 반영

기존 V51 웹스튜디오 `main`을 기준으로 V52는 **모든 업종에 공통 필터 화면이 먼저 나온다**는 문제를 해결하기 위해 대표 3종을 디자인·메뉴·정보 구조·고유 기능까지 다르게 제작합니다.

**제조·도매:** 기술 문서 느낌의 B2B 페이지. 실제 클라이언트 JS로 제품 8개 검색/재질 분류/제품군 선택/품목 MOQ 검증/견적 TXT를 실행합니다. 실제 재고/가격/발주/ERP는 없음.

**학원·교육:** 학부모 관점의 온화한 교육 브랜드 페이지. 8개 가상 수업의 학년/과목 검색, 주간 일정, 동일 요일 시간 충돌 감지, 관심 수업 TXT. 실제 학생 개인정보 수집/접수/수강료 결제 없음.

**인테리어·시공:** 벡터 공간 컨셉을 활용한 편집형 포트폴리오. 공간별 프로젝트 6개, 직접 조작하는 전후 슬라이더, 면적 검증과 상담 메모 TXT. 실제 시공 사진·실적·확정 견적 없음.

세 대표 판매 페이지의 첫 시연 CTA는 `flagship/{industry}.html`로 향하고, **기존 36개의 디자인 시연 링크는 삭제하지 않고 별도 비교 링크로 유지합니다.** 기존 디자인 갤러리 상단에는 3개의 업무형 독립 시연 카드와 실제 시연임을 명확히 하는 공지를 추가합니다. 새 3종에는 `noindex,follow`를 적용합니다.

**검증:** 격리 Chromium HTML/CSS/JS 124/124 (320/390/768/1440), 정적 65/65, 패치 14/14. HTML 각자 고유한 섹션/필터/메뉴. 원본 사진/상용 서드파티 라이브러리/API 호출 없음. 실제 Cloudflare 배포와 수신 메일/검색 색인은 별도.

**향후 36종:** 3대표작 실제 운영 QA와 첫 유료 제작 확보 이후 다른 업종은 단순 색상/텍스트 교체가 아닌 사용 목적별 독립 UX로 단계별 개편.
