## 최종 사업 목표

처음 방문한 고객이 **업종별 디자인과 실제 동작하는 기능을 체험**하고, 필요한 제작 범위·예상 예산·외부 연동 조건을 이해한 뒤 **실제 제작 상담까지 연결**하도록 만드는 것이다. 가상 시연과 고객 납품 사례는 명확히 구분한다.

## 개발 시작 시 검증

- Cloudflare Pages 실제 공개 주소와 `assets/current-release.json`을 시작 단계에서 조회했지만 도구가 접근을 차단했다. **실제 공개 버전은 미확인**.
- 연결된 운영 GitHub `main`의 `assets/current-release.json`은 V32였음.
- 메인 `assets/main.js`에서 메일 주소가 유효할 때 `#lead-note` 전체의 `textContent`를 덮어써 기존 V32 제작 상담 링크가 사라지는 오류 확인.
