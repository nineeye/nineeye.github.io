# 올파일원 웹스튜디오 V47 — 실제 고객 문의 누락 방지

## 목적
기존 V46의 준비키트→상담서 안전 연결은 요청사항 입력칸 700자 제한 때문에 전체 가상 준비자료가 메일에 포함되지 않을 수 있습니다. V47은 실제 고객이 메일을 직접 보낼 때 **받는 사람, 제목, 상담서 본문, V46 시작키트 원본**을 한 문서로 모아 확인·복사·TXT 저장합니다.

## 변경
- 웹스튜디오 `contact.html`에서 신규 V47 이메일 패킷 UI를 표시합니다.
- `assets/v47-mail-packet.js`: 수신자·제목·상담서·준비키트 원본 합치기; 사용자 명시 클릭일 때만 복사/파일 저장; 발송 전 미리보기.
- `assets/v47-mail-packet.css`: 모바일 최소 360px, 키보드 포커스, 긴 메일 내용 자동 줄바꿈.
- 기존 V26/V39/V42/V45/V46 기능 제거·변경 없음.
- 링크 이동만으로 메일이 전송됐다고 표시하지 않으며 실제 수신 여부 미검증을 명시.

## 검증 경계
- 독립 격리 Chromium 360/768/1440px 및 위험한 사용자 문자열로 74/74 PASS.
- V46 원본 노트/상담서 간의 상호작용은 실제 Cloudflare 도메인에서 시연 검증한 결과가 아님.
- 외부 발송 API, 서버, 수신 확인, 고객 정보 DB, 유료 분석 서비스 없음.
- 소유자의 실제 받은 편지함 수신 테스트·네이버/구글 검색 소유인증은 아직 HOLD.

## 적용
기존 V46 이상 GitHub checkout이 필요합니다. ZIP 전체를 압축 해제한 다음:
`python webstudio/tools/apply_v47.py --target-root "C:\\your-repo" --package-root "."`
두 번째 실행해도 같은 파일을 중복 삽입하지 않습니다. ZIP 자체는 **전체 GitHub 저장소가 아니라 V47 추가·인계 파일**입니다.
