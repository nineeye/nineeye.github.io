# 올파일원 웹스튜디오 V42 — 전체 내부링크 감사·웹메일 제작문의 개선

2026-11-08 · 본래 목표: 업종별 맞춤 홈페이지를 전문적으로 보이고 실제 제작 상담으로 연결.

## 이번 개선
1. **GitHub 실소스 정적 링크 감사**: 최상위 HTML 21개 + 업종별 12×3 디자인 36개 = 총 57개 페이지의 href/src/action 상대 파일 대상 경로를 각각 소스 트리와 대조. **확인된 누락 0개**. 일부 디렉터리 대상 링크는 파일 누락이 아니라 실제 존재하는 디렉터리로 판정.
2. `assets/v42-webmail-guide.js` + `v42-webmail-guide.css`: V40 주소 복사 안내 아래에 **'제목·상담 요청서 함께 복사'**를 추가. 필수 업종과 제작 목적 미선택 시 오류. V26/V39에서 생성한 정확한 상담 미리보기 전체를 복사하며, 사용자가 선택한 업종별 기능도 유지.
3. 고객이 원하는 경우 `https://mail.naver.com/`을 직접 새 창으로 열 수 있는 선택 링크 제공. 외부 링크는 사용자 직접 클릭에서만 작동하고 `noopener noreferrer` 포함.
4. **실제 전송 전에는 접수 상태로 오인하지 않도록** 복사·메일 앱 오류·사용자 선택 안내 모두에서 '직접 보내기' 고지. 브라우저 자동 발송, 백엔드 저장·유료 API·트래킹 없음.
5. `tools/audit_local_site_links.py` 신규: GitHub 전체 정적 사이트를 Windows 등에서 내려받아 로컬에 보관했을 때 상대경로·사이트 밖 경로·잘못된 앵커를 반복 감사하는 표준 라이브러리 스크립트. 원본 파일 변경 없음.
6. 메인 V42 배지, 공개 릴리스 JSON, 연락처 페이지의 새 CSS/JS 연결. V38~V41 기능·36개 시연·금액 예시·계약 안내는 변경하지 않음.

## QA
- 격리 Chromium 320, 360, 390, 768, 1280px에서 **59/59 검사 PASS**: 복사 기능·미선택 차단·선택 기능 보존·URL 리다이렉트 안전성·사용자 전송 고지·중복 삽입·클립보드 차단·가로 넘침 및 로컬 스캐너 정·반례.
- Node JS 문법, Python 2개 문법, CSS tinycss2 파싱 PASS.
- GitHub V42 브랜치 실제 코드·메타·기존 상담 기능 연결 12/12 PASS.
- **주의**: 57개 경로 감사는 **정적 href/src/action**에 한정, JS 동적 링크/Cloudflare 실제 HTTP·실메일 수신은 별도 검증 필요. Chromium 테스트는 실제 Cloudflare 페이지가 아닌 격리 DOM.
- 공식 Cloudflare **V41** 배포 성공 검증: https://github.com/nineeye/nineeye.github.io/runs/128632850234 . V42는 병합 뒤 별도 check-run 확인 필요.

## 반복 작업 방법
- 전체 GitHub 소스를 받은 Windows PC에서:
  `py -3.14 webstudio/tools/audit_local_site_links.py --root webstudio --output site_links_audit.json`
- 필요시 `--fragments`를 추가하면 HTML id 대상으로 연결한 앵커도 확인. 단 JS로 동적으로 만드는 앵커는 오검출 가능하므로 분리 검토.
- 다운받은 완성 ZIP은 500MB 미만, 내장 SHA 원장·CRC 검증, 기존 V41 패키지를 BASELINE으로 보존한다.
