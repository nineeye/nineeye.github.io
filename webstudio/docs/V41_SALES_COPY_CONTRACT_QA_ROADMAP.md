# 올파일원 웹스튜디오 V41 — 판매 안내 정확성·납품 범위 투명성 개선
2026-11-08 / 고객이 믿고 의뢰할 수 있는 홈페이지 제작사라는 본래 목표에 집중.

## 확인한 실제 문제
1. V39에서 기능 선택은 상담 준비서로 전달되도록 수정했으나 V38 판매 페이지 3곳에는 아직 **'선택 항목은 상담 페이지로 자동 전송되지 않는다'**는 낡은 안내가 있었음.
2. `guide.html`의 '29/59/99만원부터' 표기는 `plan-guide.html`의 '기획용 예시 가격' 안내와 다르게 읽힐 위험이 있었음.
3. 계약 전에는 수정 횟수·도메인 및 호스팅·별도 API 비용·최종 납품물·계정 소유권을 확인해야 하는데 안내 위치가 분산됨.

## V41 수정
- `for-manufacturing.html`, `for-academy.html`, `for-interior.html`: 기능 전달 사실과 수동 이메일 전송 안내를 정확하게 일치시킴. 자동 접수·실예약·실결제 없음.
- 세 업종 페이지에 `guide.html#handoff` 납품·계약 기준 직접 링크 추가.
- `guide.html`: '예시 29/59/99만원'으로 정직하게 표시하고 최종 판매가격·수정/납품 범위·추가 비용은 개별 계약 전 서면 확정으로 명시.
- 동일 페이지의 '제작 시작 전 확인할 네 가지'를 여섯 가지로 확장: 콘텐츠, 기능, 수정/검수, 소유권·인계, 외부 비용·결제주체, 납품 확인·지원 범위.
- 낡은 `start.html` 제작 준비서 CTA를 현재 `contact.html`로 연결하고 홈 `#delivery`에 새 계약 기준 링크.
- V41 메인 버전 포인터만 업데이트, 기존 36개 시연·무료 진단·상담 JS·운영 API·상용 라이선스는 변경하지 않음.
