# 올파일원 웹스튜디오 V31 — 기능 선택부터 제작 상담까지

작성: 2026-11-07 · 운영 저장소: nineeye/nineeye.github.io/webstudio

## 최종 목표
업종별로 디자인과 실제 작동하는 기능이 다르다는 것을 보여주고, 고객이 원하는 기능을 직접 선택하여 제작 상담 내용을 완성하게 한다. 실제 납품 실적이나 자동 예약·결제 기능을 허위로 표시하지 않는다.

## 사용자 제안 반영 — 배포 확인 시간 활용
Cloudflare Pages가 Git 연동 + main 자동 배포로 설정돼 있다면, main 브랜치 변경 시 자동 배포 작업이 시작된다. 완료 시각은 고정되지 않는다. 따라서 **개발 → 격리 브랜치 검증 → PR 병합 → ZIP/QA/MD 인계 → 마지막에 공개 URL 응답 확인** 순서를 채택한다.
- 참고: https://developers.cloudflare.com/pages/configuration/git-integration/
- 참고: https://developers.cloudflare.com/pages/get-started/git-integration/
- 주의: GitHub 소스의 버전과 Cloudflare가 실제 반환하는 버전은 서로 다를 수 있다. 이 환경에서 Cloudflare 도메인 직접 접근 실패 시 실배포는 미검증으로 표기한다.

## 보안·비용
- 사용자 식별자, 실제 메뉴 주문·진료·가상 비용 등을 URL로 넘기지 않음
- 기능 선택은 숫자 인덱스(0,1,2,3)만 허용
- 상담서 작성·파일 저장·메일 앱 초안은 사용자의 브라우저에서만 처리
- 새로운 외부 유료 API, 회원 서버, 쿠키·추적을 추가하지 않음

## QA 통과 조건
- 12업종 × 4개 기능의 실제 코드 제목과 상담 표시가 일치
