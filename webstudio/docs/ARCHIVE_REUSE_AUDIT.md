- `reuse-lab.html`: 추가 3업종의 정적·접근성 중심 프런트엔드

기능은 **시연 데이터만 사용**하고, 서버 전송·실제 예약·운송 API 조회·고객 결제·민감정보 수집을 하지 않습니다. `contact.html`의 업종 선택에는 위 3개 업종을 추가하여 안내가 누락되지 않도록 했습니다.

## 3. 별도 관리하는 기존 운영판 기능

- 기존 **12업종×4기능=48개**, **36개 원본 데모** 및 무료 시안 제작기·기능 설계실은 유지합니다.
- 추가 3개 업종은 별도 `reuse-lab.html`에서 체험합니다. 이 페이지를 기존 36개 데모로 잘못 계산하지 않습니다.
- 현재 단계는 **기존 48개 + 보관소에서 복원한 추가 12개 = 총 60개 프런트엔드 시연 기능**입니다. 15개 업종의 45개 독립 디자인 데모를 확보한 것은 아닙니다.
