# 올파일원 웹스튜디오 V36 — 본래 상용화 목표 중심 개선

2026-11-08 (Asia/Seoul)

## 본래 목표

**전문 웹사이트 제작사처럼 신뢰받고, 업종별로 실제 작동하는 시연을 보여주며, 유료 제작 상담으로 연결되는 올파일원 웹스튜디오**. Windows QA1/BXPRO 자동 빌더 완성은 본 목표의 필수 선행 작업이 아니므로 V36 범위에서 제외.

## 사용자에게 보이는 기능

- 홈페이지 첫 화면에 '내 사업에 맞는 홈페이지 무료 설계 진단' 진입 버튼.
- `/fit-check.html` 신규 오리지널 반응형 화면. 12개 업종 × 4개 고객 목표 × 3개 시각 스타일의 144가지 입력 조합을 조건 분기로 설명함.
- 업종별로 실제 고객이 찾을 정보·가능한 인터랙션·도입 전 확인사항을 제시함. 이는 **사용자 선택형 가이드**이지 방문 사이트 실제 자동 감사나 AI 생성 서비스가 아님.
- 12×3=36개 실제 `webstudio/demo/{industry}/{modern|premium|editorial}/index.html` 경로로 직접 이동.
- 기존 `contact.html?source=demo&industry=...&theme=...`로 업종 및 디자인을 인계하여 상담 준비서 자동 선택.
- 로컬 TXT 다운로드. 서버 제출·결제·예약·계정 생성 없음.
- 외부 CDN/폰트/사진/서드파티 패키지 추가 없음. 상업 라이선스 검토 대상 추가 없음.

- 신규: `webstudio/fit-check.html`, `webstudio/assets/v36-entry.css`, `webstudio/assets/release-v36.json`
