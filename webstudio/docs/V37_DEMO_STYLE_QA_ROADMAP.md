## 고객 경험 개선
1. 어느 시연 사이트든 같은 업종의 모던/프리미엄/에디토리얼로 이동 가능. 현재 스타일 aria-current 표시.
2. '이 디자인으로 상담하기' 링크에 source=demo, industry, theme를 보존해 기존 contact.html의 사전 선택 기능 사용.
3. 모바일 360px min-content overflow 가드, 버튼 높이, 카드/헤더/컬러/시각적 위계 개선.
4. 이용자가 가상 브랜드와 실제 납품 실적을 혼동하지 않도록 고지 유지.
5. 직접 HTML 코드를 36번 복제하지 않고 공유 파일 2개만 변경. 무료 원본 코드, 외부 서비스/과금 없음.
