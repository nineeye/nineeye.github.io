# 올파일원 웹스튜디오 V38 — 업종별 판매 랜딩 및 상담 연결 QA

날짜: 2026-11-08 · 배포 소스: nineeye/nineeye.github.io / webstudio/

## 본래 사업 목표
고객이 업종별로 필요한 정보·기능을 이해하고 **자체 제작 가상 HTML 시연 → 제작 범위 선택 → 상담 준비서**로 진입하게 하는 것.

## 이번 반영
- 신규 **제조·도매 / 학원·교육 / 인테리어·시공** 독립 판매 HTML 3종 및 각 업종별 시각적 아이덴티티.
- 신규 V38 JS로 4개 기능을 선택하면 실시간 요약/메모 복사/TXT 저장. 서버·브라우저 저장소·유료 API·추적 SDK 없음.
- 기존 36개 시연으로 가는 업종별 링크와 기존 `contact.html?source=demo&industry=...&theme=modern` 사전 선택 링크 연결.
- 메인 홈페이지 첫부분에 V38 업종별 상품 카드 3종 추가. 사이트맵 3개 URL 추가, 최신 릴리스 V38.
- 기존 견적·V36 진단·V37 36개 시연 기능 소스 직접 수정하지 않음. 실예약/실결제/고객 납품 실적을 주장하지 않음.

## 자동검증 결과와 경계
1. 실제 신규 HTML 3개+공통 CSS/JS를 **격리 Chromium DOM**에서 시험: **179/179 PASS**. 3 업종×5 너비(360~1440px), 4개 기능 선택, 내보내기 TXT, 비선택 차단, 가로 넘침, JS 오류, 메타태그 및 업종 링크.
2. 신규 홈페이지 진입 섹션+원본 CSS를 **격리 Chromium DOM**에서 시험: **26/26 PASS**. 7 너비(320~1440px), 카드 3개, 반응형 열 수, 가로 넘침, 고정 링크.
3. 실제 GitHub V38 분기의 9개 파일을 다시 읽어 URL·사이트맵·버전·4기능·파일 연결을 대조: **28/28 PASS**.
4. 합계 233개는 **서로 다른 세 범위의 개별 검사 수 합계**, 실서비스 브라우저 E2E 233건 통과를 의미하지 않는다.
5. 격리 환경이 HTTP localhost 요청을 차단하여 Playwright에서 직접 네트워크 URL을 연 통합 시험은 **NOT_RUN**. 실제 Cloudflare Pages에서 HTTP 200/JS 렌더/이메일 수신까지 통과했다고 주장하지 않음.

## 제품 기능 검증 및 판매 기준
- 각 업종 '기능 선택기'는 **상담 참고 메모** 생성이며 실제 견적 산출이나 유료 기능 사용 약속이 아님.
- 외부 DB·예약·결제·알림 운영 기능은 사이트 내 시연과 구분하고 실제 계약 시 범위/요금/개인정보 처리를 명시한다.
- 사용자 회사 실적·고객 후기·시공 사진을 꾸며내지 않는다.
- 원본 V37 소스와 33개 소스 본파일은 이 변경에서 변조하지 않는다.
