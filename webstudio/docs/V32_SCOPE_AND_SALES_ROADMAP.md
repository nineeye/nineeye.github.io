# 올파일원 웹스튜디오 V32 — 제작 범위 명확화 / 상용화 로드맵

> 작성일: 2026-11-07. 운영 GitHub: `nineeye/nineeye.github.io/webstudio/`. 정적 시연용 기능이며 실제 계약 또는 납품을 뜻하지 않습니다.

## 변하지 않는 제품 목표

처음 방문자가 **디자인·업종별 기능의 실체를 보고 신뢰**할 수 있고, 직접 기능을 조합해 **제작 범위와 운영 의존성을 이해한 뒤 실제 상담**으로 자연스럽게 이어지는 홈페이지 제작 서비스를 구축합니다. 업종별 디자인 품질을 전문가 수준으로 높이는 작업은 별도로 남았습니다.

## 기능 검증

- 로컬 Chromium: 360, 390, 768, 1280, 1440px × 기본/외부 연동/정적 충돌/관리자 운영/V31 선택 기능 연계 = **25/25 PASS**.
- 선택 입력부터 설명, 미리보기, TXT 다운로드, 이벤트 중복 없이 업데이트, JS 오류/가로 넘침 없음.
- `node --check` JS PASS / `tinycss2` CSS 파싱 PASS.
- GitHub 병합 후 blob SHA·최신 버전 파일·GitHub 변경 목록 재검증.
- Chrome 자동화는 격리 DOM 시험이며 실제 Cloudflare HTTP 또는 메일 서버 전송 시험과 다릅니다.

## 고객에게 반드시 알려야 할 것

1. 예시 계산은 실제 확정 견적이 아닙니다. 실제 가격/일정은 업무 범위를 협의한 후 확정합니다.
2. 예약·결제·회원·관리자·배송/진료 실자료는 현재 데모 기능이 아닌 별도 연동/운영 계약 대상입니다.
3. 홈페이지 자체에서 개인정보를 수집하거나 문의를 자동 접수하지 않습니다. 사용자의 이메일 앱에서 직접 발송해야 합니다.
4. 콘텐츠·사진 사용권, 도메인/호스팅 계정 소유자, 유지보수 범위 등은 계약 전에 확정해야 합니다.
