# 올파일원 웹스튜디오 V35 — 상품 비교·선택 연계·운영비 투명화
작성일 2026-11-07. 소스 위치: nineeye/nineeye.github.io/webstudio/.

## 제품 목표
실제 업종별 샘플을 직접 체험한 잠재 고객이 기본 소개형/업종 맞춤형/업무 기능형 중 어떤 구성에 해당하는지 이해하고, 추가 선택과 실제 운영 조건을 확인한 뒤 상담 준비서로 이동하도록 한다. 가상 시연을 실제 고객 실적으로 주장하지 않는다.

## 이번 개선
- 기존 디자인 갤러리(12업종×3시안)를 복제하지 않고 그대로 재사용.
- 고객이 혼동하기 쉬운 제작 범위, 실운영 기능, 도메인, 계정, 유지보수 차이를 분리.
- 3가지 기본 상품을 표와 카드로 비교. 표는 **기획 참고**이며 계약상 확정 납품 범위를 뜻하지 않는다.
- 기존 V33 상품·추가기능 예시 금액을 공통 모델로 직접 계산.
- 15개 업종/3디자인/3상품/5추가 기능을 검증된 식별자로 전달.
- 가격 또는 임의 문자열을 전달하지 않고 기존 상담서에서 자체 재계산.
- 고객 브라우저에서만 요약문 생성·복사·TXT 다운로드. 자동 계정/회원/결제/메일 발송 없음.
- 필요한 업종 선택 전에 상담 CTA를 비활성화하고 명확한 한국어 안내.
- URL 임의 값·잘못된 업종/디자인/상품 값 무시.
- 모바일 320px부터 반응형 UI, 키보드 초점 강조, 축소 동작 대응.
- 새 페이지 SEO 메타/정식 URL·사이트맵 등록.
- 메인 가격·체험 증명·상담 페이지에서 새 비교 화면 진입.
- 동일 출처 공개 파일 점검을 V35로 갱신. V33·V34 검사 보존.

## 시험과 한계
- 로컬 Chromium 새 페이지 독립 렌더·동작 102/102 PASS: 320~1440px 가로넘침 없음, 15업종/3상품/3디자인/5옵션, 무효 쿼리, 상담 링크, TXT 저장, 초기화, 한국어 안내, JS 오류 0.
- Python html.parser ID 중복 검사 PASS, Node.js --check 신규 JS PASS, tinycss2 CSS 파싱 PASS.
- 로컬 검증은 V33 공통 가격 모델의 동등 로컬 사본과 새 V35 페이지를 사용한 격리 브라우저 시험. 실제 Cloudflare 페이지 전체 종단 QA로 과장하지 않는다.
- GitHub 리포지토리 원본의 정적 구조·파일 존재는 별도 확인.
- 실제 Cloudflare Pages 공개 버전, 실메일 발송·수신, 실결제·실예약과 계약 범위는 검증되지 않았다.
- 외부 유료 이미지, 유료 폰트, 유료 API, CDN 라이브러리 도입 0원.
