# 올파일원 웹스튜디오 V48 — 실제 공개 판매 흐름 QA

## 목표
V40의 공개 파일 진단 기능을 삭제하거나 복제하지 않고, 최신 V45→V47 고객 의뢰 연결 경로까지 검사합니다. 기존 36개 디자인·3업종 체험·상담 준비서·수동 이메일 흐름은 변경하지 않습니다.

## 추가 기능
- `site-check.html` 안에 최신 판매 여정 검사판을 덧붙입니다.
- 실제 공개된 동일 출처 파일 **16개 검사항목**을 자동으로 확인합니다. 미응답/내용 불일치를 분명히 `확인 필요`로 구분합니다.
- V45 시작키트, V46 1회 인계, V47 전체 메일 패키지, 3업종 판매 페이지, FAQ, 검색 robots/sitemap, 플랜·디자인 화면을 점검합니다.
- 동적 진단 화면의 각 검사 결과를 TXT 저장/복사 가능. 네이버 서치어드바이저/Google Search Console 공식 등록 링크 제공.
- 방문자 메모·이메일·비밀키·관리자 API에 접근하지 않습니다. 외부 유료 API, 트래킹, 자동 접수·발송도 없습니다.
- 실제 고객 이메일 수신·운영 서비스 가입·검색 색인·Cloudflare 상태까지 검사하는 것으로 주장하지 않습니다.

## 적용 범위
- 신규 `assets/v48-sales-audit.js`, `.css`, 본 문서, QA 코드 및 결과.
- 기존 `site-check.html`에 CSS/JS 참조 추가만 수행.
- `assets/current-release.json` 갱신 및 `assets/release-v48.json` 생성.
- 기존 V40 검사와 기존 파일 모두 유지.
