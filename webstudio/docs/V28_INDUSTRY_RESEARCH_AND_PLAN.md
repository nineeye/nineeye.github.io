## 구현 설계

- 각 업종에 **4개 이름 붙은 독립 기능**을 제공한다: 12 × 4 = **48개**. 기존 V23·V24 가상 계산·검색 기능도 보존한다.
- 홈페이지 디자인은 Stitch 결과가 아직 없으므로 기존 V22~V27 구조를 유지하고, 모바일 접근성을 고려한 기능 패널만 추가한다.
- 데이터 모델 `assets/v28-catalog.js`: 업종/기능/가상 샘플/단위·제약 설정을 포함한다.
- 실행기 `assets/v28-tools.js`: 검색, 단가 계산, 옵션 비교, 체크리스트, 안내 추천, 단계 진행, 시간표, 장바구니, 숙박 일수, ICS 파일 생성의 10개 **독립 기능 엔진**을 제공한다.
- 스타일 `assets/v28-tools.css`: 360px 이상 반응형, 키보드/초점/활성 상태/명확한 시연 고지.
- 통합: `assets/demo.js` 기존 공통 V23·V27 로더의 뒤에 순차 로드. **36개 개별 HTML 수정 없음**. 새 기능 실패가 기존 기능까지 깨지지 않도록 독립 격리.
- 보안·비용: 클라이언트 한정. 가상 데이터만 사용, 비밀번호·건강정보·고객정보 수집/전송/추적 없음. 외부 유료 API 0건. TXT/ICS는 사용자 브라우저가 로컬 생성.
- 운영 전 필요한 별도 작업: 실제 제품/객실/일정/시세/가격 자료 교체, 담당 업종의 정책 확인, 실 예약·결제는 서버 연동 후 별도 검증.
