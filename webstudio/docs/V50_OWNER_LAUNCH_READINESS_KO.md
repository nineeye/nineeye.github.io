# 올파일원 웹스튜디오 V50 — 첫 고객 수주 전 준비도 점검

## 목표
한국 내 제조·도매, 학원·교육, 인테리어·시공 고객이 **실제 홈페이지 제작을 의뢰할 수 있는 판매 흐름** 완성. 단순 기능 개수 확대보다 문의 수신·SEO 확인·납품 범위 합의의 미검증 요소를 노출하는 운영자 점검을 우선합니다.

## 새로운 실제 동작 기능
- `/owner-launch.html`: 검색 비색인(noindex/nofollow), 무료, 비밀 키나 고객정보를 요구하지 않는 운영자용 점검 페이지.
- **11개 자동 점검**: 현재 브라우저가 접속한 동일 사이트의 공개된 정적 파일만 GET으로 읽고 HTTP 오류 및 내용 불일치 시 HOLD 표시. 
- **10개 수동 자체 확인**: 모바일 실기, 3업종 문의 작성, 실제 발송·수신, 네이버·Google 사이트 소유 확인, 사이트맵·색인, 도메인/계약/개인정보 조건. 체크 여부는 저장되지 않음.
- **보고서**: 두 범위를 명확히 분리하여 화면 미리보기·클립보드·UTF-8 BOM TXT로 생성. 광고·분석·외부 유료 API·가입·실제 문의 전송 없음.
- `site-check.html`에서 이 페이지로 갈 수 있도록 내부 링크를 추가. 전체 사이트의 기존 V49 고객 기능·36개 디자인 데모 삭제하지 않음. `owner-launch.html`은 검색 사이트맵에 추가하지 않음.

## 검증과 한계
- Chrome/Chromium 격리 브라우저 **106/106**: 320/360/390/768/1024/1440px, 실제 DOM 동작, 모의 동일 출처 GET, 보고서 저장, HTML/JS 오류, 404 실패 시 10/11 HOLD.
- Python 표준 라이브러리 소스 검사 **51/51**.
- V49 모의 자료에 안전 적용 및 재적용·V48 거부 **20/20**.
- 총 **177/177** 통과. 이것은 **격리·모의 응답**을 이용한 검증으로 실제 Cloudflare HTTP, 실제 이메일 발송·수신, 네이버·Google 색인, 계약·매출 검증을 대체하지 않습니다.
- 정식 배포·GitHub 병합 상태는 해당 단계 완료 후 공식 저장소에서 별도로 확인해야 합니다.

## 사용 방법
1. GitHub 운영 소스의 `site-check.html` 하단에서 `첫 고객 수주 준비도 점검` 클릭, 또는 `/owner-launch.html` 직접 방문.
2. `공개 파일 11항목 검사 실행` 클릭. 실패한 파일이 있으면 HOLD 확인.
3. 고객 문의 테스트, 실제 수신 메일 확인, 검색 등록 등 소유자만 할 수 있는 작업을 직접 수행한 항목만 체크.
4. `TXT 결과 저장`으로 보고서를 보존. 인증 정보나 실제 고객 내용을 기록하지 않음.
