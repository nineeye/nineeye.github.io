# AllFileOne WebStudio V29 — 메인 포트폴리오 신뢰도 개선

> 작성일: 2026-11-07 · 운영 저장소: `nineeye/nineeye.github.io/webstudio/`

## 최종 목표

첫 방문자가 **전문성과 경험을 체감하고**, 업종별 샘플·실제 기능을 충분히 살펴본 후 제작 상담을 신청할 수 있는 상용 홈페이지 제작사 웹사이트를 완성한다. 시연과 실제 고객 납품 실적은 절대로 혼동시키지 않는다.

## 현행 운영판 점검에서 발견한 문제

1. 운영판 `assets/main.js`의 12개 업종 갤러리 카드는 실제 데모 화면 대신 `scene-*.svg` 업종 일러스트만 표시한다.
2. 이미 운영 저장소에는 12개 업종 × 3스타일 = 36개 자체 제작 데모 화면 캡처(`assets/v13-shots/*.svg`)가 존재한다.
3. 카드에서 바로 `contact.html`로 이동해 업종·스타일을 유지할 수 없고, 이전 견적 계산 화면으로만 이동한다.
4. 새 버전은 기존 자동 버전 배지의 메타데이터를 업데이트해야만 화면에 반영된다.
