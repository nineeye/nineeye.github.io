목표: 상담 상세 내용이 접수 전 복사·TXT·PDF 과정에서 분실되지 않도록 보장합니다.

## 수정 배경
기존 V72/V73에서는 V65.3 제작 범위 문서를 가져온 뒤 기본 버튼 3개는 전체 문서로 저장되지만, 옛 V42 웹메일 복사 버튼과 V47 메일 패킷 복사·TXT·미리보기, V34 인쇄 버튼은 원래 축약 미리보기만 사용했습니다. 같은 화면에서 누른 버튼에 따라 전달 내용이 다를 수 있었습니다.

## V76 변경
- V65.3 견적·계약 검토 내용이 V72/V73 전체 준비서로 가져온 경우에만 V76이 작동합니다.
- 구버전 V42 복사, V47 복사·TXT·미리보기, V34 인쇄 버튼을 최종 전체 준비서에 연결했습니다.
- V46 시작키트를 별도로 가져왔다면 최종 문서에 추가하되 같은 내용의 중복은 피합니다.
- 업종·디자인 변경으로 지난 견적이 현재와 달라지면 V73의 참고 전용 구분을 유지합니다.
- 인쇄에서는 축약 미리보기 대신 V72/V73 전체 문서가 표시됩니다.
- 상담 전송, 자동 이메일, 서버 저장, 결제, 외부 AI API는 추가하지 않았습니다.
- 견적을 가져오지 않은 일반 상담은 기존 기존 버튼 동작을 그대로 유지합니다.
