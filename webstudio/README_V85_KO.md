# 올파일원 웹스튜디오 V85 — 실제 홈페이지 체험 전시관

## 이번 개선의 목적
V84의 도형 장식 중심 프리뷰를 실제 업종별 HTML iframe으로 바꾸어, 구매 예정자가 실제 화면을 3종 나란히 보고 PC/모바일 폭에서 조작할 수 있게 합니다.

- 기존 12업종, 업종별 3스타일의 실제 HTML 36개, 48개 원형 가상 도구, 추가 36개 가상 시연 등 **기존 기능 유지**.
- `experience-v85.html`: 모던·프리미엄·에디토리얼 HTML 샘플 3종 미리보기, 실제 HTML 큰 시연, PC 1366/모바일 390 논리 폭 전환.
- `assets/v85-experience.js/css`: 업종 선택·스타일 전환·기능 목록 7(브라우저 가상 시연) + 1(실서비스 미구현 옵션)·한글 TXT 저장·기존 제작 범위 협의서로 연결.
- `index.html`: 첫 화면에 새 전시관 바로가기, 기존 V84 선택기 보존.
- `design-studio-v84.html`, `design-compare-live.html`: 새 V85 전시관으로 이동 링크 추가.
- `assets/current-release.json`: V85 additive 릴리스 메타데이터 보존. 공식 공개 베이스라인 V82를 아직 V85라고 허위 표기하지 않음.

## 기능과 제품의 경계
- 실제 홈페이지의 HTML 샘플은 가상의 업체/상품/가격으로 조작 가능하지만 **실제 고객 예약/결제/주문/회원관리/실데이터 연동/자동 이메일 접수는 구현되지 않았습니다**.
- 협의서와 요약 TXT는 브라우저에서만 작성·다운로드합니다. 사용자 정보 서버 저장과 고객 메일 자동 발송이 없습니다.
- 상품 가격은 어디까지나 예시 시작 가격. VAT, 도메인, 호스팅, 운영비, 수정 횟수, 하자보수, 소스/디자인 사용권은 개별 계약이 필요합니다.

## 검증 결과 (2026-11-09)
- V85 실제 12업종·3스타일 원본 자료를 사용한 격리 Chromium **590/590 DOM 검사 통과**, PC 1440px/모바일 390px에서 전체 가로 넘침/JS 예외 없음. TXT 다운로드 내용 포함.
- 이 실행 환경은 로컬 네트워크/iframe 요청을 브라우저 정책으로 차단하여 **실제 iframe 픽셀 로딩은 미검증**입니다. 로컬 화면캡처가 실제 iframe 시연을 입증하지 않기에 캡처를 PASS 증거로 만들지 않았습니다.
- 44개 기존·신규 실공개 파일의 정확한 HTTP 응답 검증 및 Windows Edge 실제 프레임 검증은 GitHub main 배포 후 별도 실시해야 합니다.
- 소스 정적 회귀 + 반례 검사 8/8 통과. 기존 V84 public 47/47 및 7/7 증거는 2026-11-09 이 사용자 대화의 직전 작업에서 확보했습니다.

## 오프라인 미리보기
1. 본 전체 ZIP에서 `SITE_PUBLISH_ONLY.zip`을 풀거나, `SOURCE_SITE/`를 이용합니다.
2. `RUN_V85_LOCAL_PREVIEW.cmd`를 실행합니다. `%USERPROFILE%\Downloads\AFO_WebStudio_V85_Local_Preview`에 보고서를 저장하고 브라우저를 엽니다.
3. `experience-v85.html`에서 업종·디자인·PC/모바일을 체험하고 요약 TXT를 다운로드합니다.
4. 실제 메일 발송은 별도의 이메일 앱에서 직접 하고 수신 확인이 필요합니다.

공식 Pages Git 연동 권장: Production branch `main`, build command `exit 0`, output `webstudio` (Cloudflare 설정 실제 확인 필요). 무료 자산·소형 JS/정적 파일만 이용하며 외부 유료 API를 추가하지 않았습니다.
