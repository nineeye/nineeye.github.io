- 수정 회차, 도메인·호스팅 비용 부담, 소스·계정 인계, 유지보수·하자 보수 범위, 추가 확인사항을 작성
- 10가지 협의 조건 준비도, 완성된 협의 내용 14행 즉시 미리보기
- 브라우저 내부에서 TXT 다운로드·클립보드 복사·복사권한 거부 시 수동 선택 영역·브라우저 인쇄/PDF 저장

- 실제 샘플 확인 및 `nineeyes@naver.com` **메일 앱 초안 열기**; 누르면 자동 발송 또는 접수된다고 주장하지 않음
- 제출·로그인·결제·브라우저 저장소·고객 개인정보 서버 저장·외부 유료 API 0
