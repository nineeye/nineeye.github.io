# 올파일원 웹스튜디오 V87 — 판매 전 실제 문의 준비 기능

- 12업종 고유 원본 자료로 만드는 고객 의뢰서, 3가지 디자인, 3개 범위 예시, 업종별 핵심 기능 8개.
- TXT 내려받기, 브라우저 클립보드 복사, 사용자가 직접 누르는 `mailto:nineeyes@naver.com` 메일 앱 링크.
- 작성값을 localStorage/쿠키/서버/외부 API에 전송하지 않음. URL에는 업종과 디자인 식별자만 유지.
- 고객의 이름, 연락처, 기타 개인정보 기재는 불필요. 자유 기입에는 개인정보 미입력 권장.
- 가격 29/59/99만원부터는 기존 기획용 예시이지 확정 견적·일정·납품 보장 아님. 부가세·호스팅·도메인·소스 권리·저작권·수정 횟수·유지보수는 서면 합의 필요.
- 운영 회원/결제/예약/저장/발송 시스템 미구현. 7가지 가상 브라우저 시연 + 1가지 미구현 기능 분리.
- 실제 이메일 발송·수신 확인은 미검증. 메일 앱이 없는 고객에게 TXT 저장과 복사 안내.
- 브라우저 자동화는 실제 고객 이름·메일·서버 정보가 아닌 가상 업종 정보만 사용.
