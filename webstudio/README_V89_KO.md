# 올파일원 웹스튜디오 V89: 경쟁사 비교 후 첫 화면 재설계

## 목표
국내 고객이 **업종 선택 → 원본 HTML 체험 → 제작 범위 → 제작 요청서**까지 혼란 없이 이동하도록 한다.

## 실제 수정
- 홈페이지 `index.html`을 4개 주요 메뉴/6개 판매 흐름으로 재작성 (기존 21섹션/9메뉴 축소).
- 기존 V88 긴 홈페이지는 검색 제외 `home-archive-v88.html`로 보관, 기존 자산·데모·상담·기능 페이지는 수정하지 않음.
- 제조(모던), 학원(에디토리얼), 인테리어(프리미엄) **실제 소유 HTML을 별도 Chromium 격리 화면으로 캡처**해 첫 화면과 시안 카드에 사용. 외부 제3자 고객·실적 이미지 사용하지 않음.
- 12업종 선택기는 해당 `experience-v85.html?industry=...`, `industry-guide/*.html`로 안전하게 연결. 실제 HTML 데모 36개와 84개 가상 기능은 유지.
- 공개 FAQ 신뢰 문제를 가상 시연 표기/계약·VAT·유지보수 별도 안내로 구분. 29/59/99만 원은 기획 참고이며 확정 견적 아님.
- 사이트 공유용 1200×630 PNG OG 이미지 자체 제작. 원본에서 작성한 상호작용은 서버 저장/자동메일/API 사용 없음.

## 절대 미완료
- 실제 고객 납품 실적·후기·사업자 정보 확인, 실제 네이버 메일 수신과 회신, 확정 가격·VAT/수정횟수/납품기간/유지보수/계약, Cloudflare 최신 SHA 자체확인.
- 무료 QA는 구매/문의 접수 증명이 아니다. `mailto:`는 메일앱 수동발송이다.
