04 / TRANSPARENT TERMS

고객이 자주 확인하는 사항

확정되지 않은 서비스 수준·실적·가격을 약속하지 않습니다.

이 화면에서 결제나 계약이 완료되나요?

아닙니다. 이 페이지는 제작 전에 질문을 정리하는 도구이며 결제·계약·예약을 처리하지 않습니다.

29만·59만·99만원은 확정 가격인가요?

아닙니다. 기존 안내의 기획 참고 시작가이며 페이지 수·기능·자료 준비 상태에 따라 달라질 수 있습니다. 견적과 부가세 포함 여부는 서면 확정이 필요합니다.

시안의 브랜드나 리뷰가 실제 납품 고객인가요?

아닙니다. 36개 샘플은 가상 브랜드로 만든 원본 HTML 체험 페이지입니다. 실제 고객 납품·후기로 표시하지 않습니다.

실제 예약·회원·결제가 기본 포함되나요?

아닙니다. 가상 기능 시연과 실제 운영 서버·결제·개인정보 처리는 구분하고, 필요할 때 범위·보안·비용을 별도로 검토합니다.

문의 작성만 하면 자동으로 전송되나요?

아닙니다. 요청서 파일을 만들거나 이메일 앱을 열 수 있지만 고객이 직접 전송해야 접수됩니다. 실제 메일 수신 여부는 확인이 필요합니다.

수정 횟수·유지관리·소스 소유권은 어떻게 되나요?

정해진 일괄 조건이 아닙니다. 제안서·계약서에 페이지와 소스 범위, 수정 회차, 호스팅, 유지관리, 자료 권한을 각각 명시한 뒤 합의합니다.
