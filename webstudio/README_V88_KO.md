# 올파일원 웹스튜디오 V88 — 실제 문의 수신 준비와 판매 운영 점검

## 이번 기능
- 기존 V87 고객 상담 요청서에 **받는 주소 / 제목 / 본문** 각각 복사 버튼 추가. clipboard 권한 차단 시 사용자가 직접 선택하는 텍스트 영역을 제공.
- 기존 12개 업종·36개 실제 HTML 샘플·84개 가상 기능 시연·V87 기능 선택 그대로 유지.
- `launch-readiness-v88.html`에 5개 범주, 30개 **수동 확인** 체크리스트. 모두 기본 미확인. 사용자 본인이 선택해야만 수치가 바뀜.
- 실제 메일 수신을 확인하는 **타 계정 발송 → 네이버 수신 → 운영자 답장 → 발신 계정 회신 확인** 절차를 안내하지만 프로그램이 실제 메시지를 보내거나 읽지 않음.
- 점검 TXT는 브라우저에서만 생성. 비밀키·고객명·전화번호 입력 금지; 자동 서버/네트워크 접수, localStorage, 쿠키, 결제, 추적 없음.

## 로컬 확인
소스/브라우저 검증: `python -m unittest discover -s webstudio/tools -p 'test_v88*.py' -v`; `python webstudio/tools/v88_dom_browser_qa.py --root webstudio --output <폴더>`.

## 주의
- 사용자가 체크박스 30개를 누르는 것은 독립적인 실증이 아닙니다. 이메일 실수신·답장·가격/VAT·계약·고객 납품 검증은 **남은 업무**입니다.
- Cloudflare 무료 한도는 계약/설정에 따라 달라질 수 있습니다. 기존 계정에 유료 설정을 추가하지 않습니다.
- 운영 체크 화면은 공개 정적 페이지이며 `noindex`는 인증 또는 비공개 통제가 아닙니다. 개인정보나 운영상 비밀이 들어 있지 않습니다.
